# cps_product

The test product of the cps_development main repo — a tactical scenario
simulation environment: recon an area, hunt moving and static targets,
one integrated co-simulation system.

v0 fidelity: 2D point kinematics and ideal sensors. Scenarios are
parameter sets, parsable and injectable, run through pyssp_simulate.

Tracked as a submodule at `extern/product` in cps_development.
Development on custom branches only, never on main. The main repo's
breakdown owns the product shape and goals.
